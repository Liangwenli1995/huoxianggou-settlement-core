Computer Code Availability

A compact, executable release of the author-developed core analysis is openly available at [PUBLIC REPOSITORY URL] under the MIT License. The repository contains English-language source code, dependency specifications, a synthetic quick test, and instructions for running it. The released routines cover deformation smoothing and differencing, leakage-free antecedent-rainfall windows, chronological random-forest validation, optional SHAP attribution, and hyperbolic consolidation fitting. Private data, account-specific assets, local path configuration, production batch utilities, cartographic routines, and manuscript-specific figure formatting are not distributed because they are not required to inspect or execute the core methods. Sentinel-1 SBAS preprocessing used the third-party software identified in the manuscript; no author-developed source code was used for that preprocessing step. The public repository permits anonymous viewing and download without registration.
